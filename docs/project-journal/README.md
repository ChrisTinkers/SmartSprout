# SmartSprout – Projektjournal

**Stand:** 15.11.2026  
**Status:** Hardwareplanung weitgehend abgeschlossen; Aufbau und elektrische Inbetriebnahme stehen aus.

## Projektziel

Automatische, individuell steuerbare Bewässerung von zunächst vier Zimmerpflanzen auf dem Kamin, ausgelegt auf bis zu sechs Pumpenkanäle. Anforderungen: leiser Betrieb, Wartungsarmut, Überwachung von Wasserstand und Leckage sowie Integration in Home Assistant.
